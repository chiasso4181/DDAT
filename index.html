⚠️ Avvio da Cartella di Rete non consentito

Hai aperto il file index.html direttamente dalla cartella condivisa aziendale. Per motivi di sicurezza di Windows, da questa posizione il salvataggio sul file Excel è bloccato.

  1. Chiudi questa finestra del browser.
  2. Nella cartella di rete, fai Tasto destro sul file index.html e scegli Copia.
  3. Vai sul tuo Desktop (oppure nella tua cartella Downloads), fai Tasto destro e scegli Incolla.
  4. Apri index.html facendo doppio clic sulla copia che hai appena messo sul tuo Desktop / Downloads.
